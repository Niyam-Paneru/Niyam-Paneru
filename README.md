# Niyam Paneru

Hi, I'm Niyam. I build backends, automation, voice stuff, and side projects that have a habit of getting bigger than planned.

I have a particular weakness for the question **"but did it *actually* work?"** A timeout isn't a failed action, a green test isn't a deployed app, and an AI saying "done" is not a receipt. I learned to be suspicious of all three.

## A few things you can poke around in

**[reastream](https://github.com/Niyam-Paneru/reastream)** — I had a 1.26 GB analysis output and wanted a tiny part of it. So I wrote a Rust streaming reader. On the [recorded test](https://github.com/Niyam-Paneru/reastream/blob/main/docs/measurements/README.md), it kept 6.55 MB of records instead of loading the whole file. My laptop and I both appreciated that decision.

**[Best Tech Solutions website](https://github.com/Niyam-Paneru/bts-website-preview)** — an actual [website you can click through](https://niyam-paneru.github.io/bts-website-preview/), with laptop galleries, product pages, services, and WhatsApp enquiries. It's a client *preview*, not a finished production launch. No made-up inventory, either.

**[Attended Browser Bridge](https://github.com/Niyam-Paneru/attended-browser-bridge)** — the part of browser automation that asks whether a write is permitted, whether the page is still the page we inspected, and whether we might have already clicked Submit. Double-submitting a form is a terrible retry strategy.

**[AI Booking Workflow](https://github.com/Niyam-Paneru/ai-booking-workflow)** — a small Python state machine that refuses to confirm a time it never offered. The code doesn't talk to a real calendar; it does, however, know that imagination is not availability.

More experiments are in the [repositories tab](https://github.com/Niyam-Paneru?tab=repositories). Some are standalone tools; some are deliberately small, runnable pieces of bigger private projects. Each repo should say what it does *and* what it doesn't.

## What I'm usually messing with

DentSignal (voice-receptionist work), Browser Bridge (browser control), Niyam-AI (memory and agent experiments), and whatever problem has distracted me this week. The [old DentSignal Twilio code](https://github.com/Niyam-Paneru/dentsignal-twilio-evidence) is public as historical evidence, not a live phone system.

I mostly reach for Python, FastAPI, JavaScript/TypeScript, Node.js, Playwright, PostgreSQL, and Rust.

Also C, whenever I want the computer to remind me that memory has consequences.
